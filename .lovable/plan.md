Одна кнопка в шапке приложения, которая одним подтверждением сбрасывает всё рабочее состояние: сохранённые OKR (дерево), Solution Studio, документы и текущий черновик генератора/аудита.

## Не трогаем
- Существующие кнопки сброса в модулях (DocsManager, SolutionStudio, SavedOkrsList) остаются.
- Логику edge-функций, промпты, useSavedOkrs API.
- Дизайн-систему: только shadcn `AlertDialog` + `Button` + иконка lucide, без новых цветов/шрифтов.

## Технические детали
- Иконка: `RotateCcw` из lucide-react (уже в проекте).
- Ремоунт `SolutionStudio` через `key={studioKey}` — самый безопасный способ синхронизировать внутреннее состояние хука с очищенным localStorage без экспорта хука наружу.
- `toast.success("Все данные сброшены")` после выполнения.
- `objective` возвращаем к дефолту «Стать самым любимым онбордингом» (текущее начальное значение).
